# Ready-to-upload PNGs

Rendered from the SVGs one directory up. Re-export from the source SVGs if you
change the mark — don't edit these.

| File | Size | Use |
|---|---|---|
| `flixit-instagram-dark.png` | 1080×1080 | Instagram / TikTok profile picture. The default. |
| `flixit-instagram-light.png` | 1080×1080 | Same, cream ground, flat ink mark. |
| `flixit-app-icon-1024.png` | 1024×1024 | App Store listing icon. |

Instagram and TikTok crop profile pictures to a **circle**, so the mark is
sized to sit inside the inscribed circle with the corners expendable. Checked
down to 32px (the story-ring size) — it still reads.

Upload at full size; the platforms downsample better than you can.
